# PPL Project

This project contains exercises and cheatsheets for Principles of Programming Languages.

## Documentation

The cheatsheets are available at: [https://scamgi.github.io/ppl/](https://scamgi.github.io/ppl/)

To update the documentation:
1. Edit the Markdown files in the `docs/` folder.
2. Commit and push your changes.
3. GitHub Pages will automatically rebuild and deploy the site.
